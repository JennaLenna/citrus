## Technical Details (For Reference):

### citrus_simple.html
- Single self-contained HTML file
- 500+ lines
- Inline CSS (beautiful purple gradient theme)
- Inline JavaScript (handles API calls, UI updates)
- Works offline (once server running)
- Responsive design

### simple_server.py
- Minimal Python HTTP server
- Auto-installs NumPy if missing
- Simple REST API (4 endpoints)
- Background training (non-blocking)
- CORS enabled
- Runs on port 5555

### START.bat / START.sh
- One-click startup
- Cross-platform
- Auto-navigates to directory
- Keeps server window open
- Clear instructions
