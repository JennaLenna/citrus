# 🍊 Citrus AI - SUPER SIMPLE START GUIDE

## The Easiest Way Ever - Just 2 Steps!

---

## Step 1: Start the Helper

**Windows:**
- Double-click `START.bat`
- A black window appears - **don't close it!**

**Mac/Linux:**
- Double-click `START.sh`
- A terminal window appears - **don't close it!**

**That's it for Step 1!**

---

## Step 2: Open the App

- Find the file named `citrus_simple.html`
- **Double-click it** - it opens in your browser
- Use it like any website!

**Done!** 🎉

---

## How to Use the App

Once `citrus_simple.html` is open in your browser:

### 1️⃣ Add Your Writing
- Paste some text you've written into the big box
- Click "Save This Writing"

### 2️⃣ Train the AI
- Choose how long to train (Normal is good)
- Click "Start Training"
- Wait 2-5 minutes

### 3️⃣ Generate Text
- Type a starting phrase
- Click "Generate Text!"
- See the AI write in your style!

## Troubleshooting

**"The page says server not running"**
- Did you run START.bat or START.sh?
- Keep that window open!

**"Nothing happens when I double-click START.bat"**
- Right-click it → "Run as Administrator"
- Or open Command Prompt, type: `python simple_server.py`

**"Can't find the files"**
- Make sure you're in the citrus folder
- All these files should be together:
  - citrus_simple.html
  - simple_server.py
  - START.bat (Windows)
  - START.sh (Mac/Linux)
