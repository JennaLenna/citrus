### 2. How to Input Your Writing

**Three options (pick what's easiest for you):**

**Option A: Use the helper script (recommended)**
```bash
python add_writing.py
```
It will help you copy your .txt files to the right place.

**Option B: Use the interactive mode**
```bash
python easy_start.py
```
It will ask if you want to add writing and guide you.

**Option C: Do it manually**
```bash
# Just copy your .txt files here:
cp my_writing.txt data/raw/
```

**What's a .txt file?**
- Open Notepad (Windows) or TextEdit (Mac)
- Paste or type your writing
- Save as "myfile.txt"

**Where does it go?**
- Into the folder: `data/raw/`

That's it!
